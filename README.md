# **🛍️ Vrinda Store Data Analysis & Sales Dashboard (2022)**

## **📌 Project Overview**

This project focuses on analyzing Vrinda Store's 2022 sales data using Microsoft Excel. The main objective is to understand customer purchasing behavior, sales performance, and business trends through an interactive dashboard.

## **🎯 Project Objectives**

- Analyze overall sales and order performance.
- Identify the highest sales and order months.
- Understand purchasing patterns based on gender.
- Analyze customer age groups.
- Identify top-performing states.
- Evaluate sales channels and product categories.
- Generate useful business insights.

## **🛠️ Tools & Technologies**

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Analysis
- Data Visualization

## **🔄 Project Workflow**

1. 📂 Data Collection – Imported the Vrinda Store sales dataset.
2. 🧹 Data Cleaning – Checked and cleaned the dataset.
3. 📊 Data Analysis – Analyzed sales, orders, gender, age groups, and categories.
4. 📈 Data Visualization – Created charts using Pivot Tables and Pivot Charts.
5. 🎛️ Interactive Dashboard – Added slicers to make the dashboard interactive.
6. 💡 Insights – Identified important sales trends and customer patterns.

## **📊 Key Business Questions**

- What is the relationship between sales and orders?
- Which month recorded the highest sales and orders?
- Which gender contributed more to sales?
- What are the different order statuses?
- Which states contributed the most to sales?
- Which age group generated more orders?
- Which sales channel performed best?
- Which product category had the highest sales?

## **💡 Business Insights**

- Analyzed customer purchasing behavior across gender and age groups.
- Identified top-performing states and sales channels.
- Evaluated monthly sales and order trends.
- Identified popular product categories.
- Explored opportunities to improve sales performance.
